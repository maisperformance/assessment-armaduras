# Assessment das Armaduras

**Workshop "Navegando pela Incerteza" — Mais Performance**

Instrumento de autoavaliação comportamental que identifica padrões defensivos automáticos no trabalho (armaduras), baseado no trabalho de Brené Brown e na metodologia da Mais Performance.

🔗 **Acesse**: [https://maisperformance.github.io/assessment-armaduras/](https://maisperformance.github.io/assessment-armaduras/)

## Estrutura

- 5 armaduras: Perfeccionismo, Controle, Autossuficiência, Agradabilidade Excessiva, Ocupação Crônica
- 25 perguntas (5 por armadura), ordem aleatória
- Resultado em percentual (0-100%)
- Devolutiva personalizada para as armaduras em destaque

## Como funciona

1. Abra o link acima no navegador (celular ou desktop)
2. Responda as 25 perguntas
3. Veja seu resultado com gráfico, destaques e devolutiva
4. Opcionalmente: salve como PDF ou exporte como texto

## LGPD

Nenhum dado é coletado. Tudo fica no navegador do respondente (`localStorage`). Para resetar, basta limpar o cache do navegador.
